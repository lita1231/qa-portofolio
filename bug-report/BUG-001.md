## Steps to Reproduce
1. Buka https://www.saucedemo.com dan login dengan `standard_user` / `secret_sauce`.
2. Klik "Add to cart" pada produk Sauce Labs Backpack.
3. Klik ikon keranjang, lalu klik Checkout.
4. Isi First Name dengan `lula` dan Last Name dengan `hehe`.
5. Isi Zip/Postal Code dengan `abc!@#`.
6. Klik Continue.

## Test Data
First Name: lula | Last Name: hehe | Postal Code: abc!@#

## Expected Result
Aplikasi menolak kode pos yang berisi huruf dan simbol. Pengguna tetap di halaman "Checkout: Your Information" dan muncul pesan error.

## Actual Result
Aplikasi menerima kode pos tersebut tanpa pesan error. Pengguna langsung berpindah ke halaman "Checkout: Overview".

## Alasan Severity (Medium)
Checkout tetap berjalan, jadi fungsi utama tidak rusak. Namun data alamat pengiriman bisa tidak valid sehingga paket berisiko salah kirim.

## Alasan Priority (Medium)
Tidak menghalangi pembelian, jadi tidak mendesak. Tetapi sebaiknya diperbaiki sebelum rilis karena memengaruhi kualitas data pesanan.

## Catatan: Mengapa Ini Dianggap Bug
Kode pos pada umumnya berupa angka (atau mengikuti format tertentu), sehingga input `abc!@#` seharusnya ditolak. Saucedemo adalah aplikasi demo tanpa dokumen requirement resmi, jadi ini diasumsikan sebagai bug dan perlu dikonfirmasi ke Product Owner.
