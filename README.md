# QA Portfolio

Portofolio belajar Quality Assurance (Software Testing) oleh **Enjelita Sitorus**.
Repo ini berisi hasil latihan pengujian nyata pada aplikasi demo [saucedemo.com](https://www.saucedemo.com) dan API demo [jsonplaceholder](https://jsonplaceholder.typicode.com).

## Isi Repo

| Folder | Isi |
|---|---|
| `catatan/` | Glosarium istilah QA yang saya pelajari |
| `test-case/` | Test case fitur checkout, decision table, dan test case API |
| `bug-report/` | Laporan bug beserta bukti (screenshot) |

## Yang Sudah Saya Kerjakan

- Menulis dan menjalankan 7 test case manual fitur checkout (positive dan negative).
- Membuat decision table untuk validasi First Name dan Last Name.
- Menemukan dan melaporkan 1 bug: kolom Postal Code menerima huruf dan simbol (BUG-001).
- Menjalankan request API dan test otomatis sederhana di Postman.

## Tools

Google Chrome (DevTools), Postman, Git dan GitHub, Visual Studio Code.

## Sedang Dipelajari

SQL dasar, API testing lanjutan, automation testing
